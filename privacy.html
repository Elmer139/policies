Privacy Policy

Last updated: 7 October 2026

What this application is

This is a private publishing tool used by a single operator to upload video content to their own social media accounts. It is not offered to the public and has no other users.

What it accesses

With the operator's explicit authorisation, the application uses the YouTube Data API to upload videos to the operator's own YouTube channel and to read back the status of those uploads. It requests no other access.

What it stores

An OAuth access token and refresh token, stored only on the operator's own computer, used solely to perform those uploads. Video files and captions created by the operator are stored on the same computer.

What it does not do

  • It collects no information from any third party.
  • It has no visitors, no analytics and no cookies.
  • It sells nothing and shares nothing with anyone.
  • It does not read, collect or store data belonging to other people.

Google user data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is used only to provide the upload function described above, is never transferred to others, and is never used for advertising.

Deleting the data

The operator may revoke access at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens. Deleting the local token file removes them from the computer.
